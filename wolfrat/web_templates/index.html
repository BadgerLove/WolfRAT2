Typed commands

Type a !command in Chat (or press ! next to the message box) and WolfRAT runs it as Web Admin. Commands are not posted in game chat. Tap one below to put it in the message box.

Another phone

On the PC, open Web Admin, press Pair a phone and scan the code with the other phone. Each phone gets its own key; sign one out under Devices any time.

Manual mode

In Manual mode WolfRAT's automatic jobs are off (welcome lines, votes, auto-balance and the like), for when another WolfRAT looks after the same server. Everything you press here, and every command you type, still works.
